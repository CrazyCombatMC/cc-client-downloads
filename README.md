# cc-client-downloads

Public build artifacts for CC Client. Fixed release tags act as feeds:
- `feed` — stable: latest.yml + installer + mods.json + news.json + mod jars
- `dev` — latest-dev.yml + PR dev installers
- `screenshots` — PR preview images
- `vX.Y.Z` — per-version archive releases

Assets are uploaded by CI in CrazyCombatMC/cc-client; downloads are anonymous via `releases/download/<tag>/<asset>`.
